Fibonacci Steganography
Abstract
1. This is to be done using cellular automata method of fibonacci series steganography method
2. The secrets bits are embedded into a higher LSB layer
3. An adaptive adjustment is done to minimise the distortion as much as possible
4. Employing the game of life, cellular Automaton, to generate the used key stream for encryption and image pixel
    selection
5. Capacity Same as classical LSB

We will be using A Secure Adaptive Adjustment Steganographic Algorithm (AAJFIBO)
three steps:
1. Pixel Color component is represented in Fibonacci representation to obtain more available bit plane
2. secret bit are embedded into high LSB layer to obtain higher robustness in comparison with LSB algo
3. Adjustment is performed which does not modify LSB and thus statistical properties of cover image is not changed

- Game of life is used AND NOW WHAT IS GAME OF LIFE?
- well it is a fun little game. there are multiple boxes/ Grid. A box have two states, alive or death
Rules
1. Any live cell that is touching fewer than two alive neighbours dies.
2. any live cell that is touching four or more alive neighbour dies
3. Any live cell touching two or three alive neighbour does nothing
4. Any dead cell that is touching exactly three alive neighbours becomes alive

Traditional Fibonacci based steganography
main algorithm
1. image pixel's value to is represented in fibonacci presentation
2. secret bit is then embedded into the fibonacci sequence by LSB ALGO
3. The f sequence with secret bit is embedded is converted to binary domain before being written to stego- image

Conceptual Framework of the proposed scheme
step 1: The password from user to produce the key stream
step 2: the secret message is encrypted by applying XOR operator to every bit using a generated key stream.
The selection is represented into Fibonacci representation. The bits are embedded in some layer of LSB layer.
adjustment algo is applied to reduce algo

step 3: the stego image is transferred to public image sharing services where the user B can download it easily without a
notice
step 4: receiver downloads stego image
step 5: private key is provided by receiver to create the initial data for producing the key stream, the generated key
stream is used to determine the color component that carry the secret bits

The used color component are  identified by the value of current bit in key stream. if it's  value is 0, the green component
is selected and vice versa

axis cheat sheet in numpy
1D Array (axis=0):

The only axis available. Operations will apply across all elements of the array.
2D Array:

axis=0: Operates along rows (vertically). For example, np.sum(arr_2d, axis=0) calculates the sum of each column.
axis=1: Operates along columns (horizontally). np.sum(arr_2d, axis=1) calculates the sum of each row.
3D Array:

axis=0: Operates along the depth (the outermost dimension). Each operation is applied to the 2D arrays stacked along this axis.
axis=1: Operates along rows within each depth level.
axis=2: Operates along columns within each depth level.
